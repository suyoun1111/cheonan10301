# 천안시 청년정책 2026 | 인터랙티브 웹 프레젠테이션

원본 PowerPoint 10장을 16:9 고해상도 이미지로 변환하여 **레이아웃, 문구, 차트, 인포그래픽을 그대로 유지**하고, 웹 UI 및 데이터 탐색 기능을 더했습니다.

## 실행

- `index.html`을 브라우저에서 열면 별도의 서버 없이 동작합니다.
- GitHub 저장소에 `index.html`, `style.css`, `script.js`, `assets/` 폴더를 업로드하세요.
- GitHub의 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` / `/(root)` 선택 후 저장하세요.
- 경로는 전부 상대경로이므로 `https://계정.github.io/저장소명/`에서도 정상 표시됩니다.

## 조작

- 상단 메뉴로 정책 분야 이동, 이전/다음 버튼, 하단 썸네일 탐색
- 키보드 ← / →, PageUp / PageDown, 스페이스, Home / End
- 모바일에서 좌우 스와이프, 프레젠테이션 위 세로 휠 스크롤
- `핵심 내용`, `데이터 탐색`, 슬라이드 안의 `+`로 상세 데이터 패널 열기
- `▦`로 전체 슬라이드 보기, `⛶`로 전체화면, `Esc`로 패널 닫기
- 주소 해시(`#slide-5`)로 특정 페이지 공유

## 구성

- `index.html` — 앱 레이아웃
- `style.css` — 반응형 스타일 및 슬라이드 모션
- `script.js` — 데이터, 내비게이션, 인터랙티브 차트 및 패널
- `assets/slide-1.png` … `slide-10.png` — 원본 슬라이드의 화면 이미지
- `source/original.pptx` — 원본 발표 자료 보관

참고: 원본 정보를 보존하기 위해 시각적 슬라이드는 이미지로 렌더링합니다. 따라서 슬라이드 내부 텍스트/도형은 HTML 객체로 개별 편집할 수 없지만, 별도의 데이터 패널에 주요 수치와 근거 링크를 웹 요소로 제공했습니다. 외부 글꼴이 로딩되지 않아도 시스템 글꼴로 정상 작동하며, 프레젠테이션 이미지와 핵심 기능은 인터넷 연결 없이도 동작합니다.
